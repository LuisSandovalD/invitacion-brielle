# Invitación de Brielle Celeste

Invitación web estática preparada para publicarse en Vercel. Los datos del evento están definidos directamente en `index.html`; los visitantes no pueden editarlos ni sobrescribirlos en su navegador.

## Publicar en Vercel

### Desde la web

1. Sube esta carpeta a un repositorio de GitHub, GitLab o Bitbucket.
2. En Vercel, selecciona **Add New > Project** e importa el repositorio.
3. Deja **Framework Preset** en `Other` y conserva vacíos los campos de comando de compilación y directorio de salida; este sitio estático no necesita compilación.
4. Selecciona **Deploy**. Vercel generará el enlace público.

### Desde la terminal

Con una cuenta de Vercel iniciada, ejecuta desde esta carpeta:

```powershell
npx vercel --prod
```

El comando mostrará el enlace público al finalizar.
